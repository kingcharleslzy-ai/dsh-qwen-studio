# 2.4.0 验证范围

## 本版自动检查

- TypeScript 类型检查、24 项 Vitest 测试、16 项 Python worker 测试。
- 同一技能源生成模型目录简介与正文；只读状态工具取回同一附件，回收站不重新展示，不启动模型。
- 单任务读取、路径边界、调用回执隔离、会话图片不受图库隐私影响、离页完成的预览恢复，以及非 JSON HTTP 错误保留状态码。
- 高级参数验证、远程明确拒绝、控制图/源图/蒙版在回执前快照、LoRA 目录边界、模型组合切换、黑色蒙版像素保留。
- 安装包不含模型、个人配置、生成图片或运行日志。

## 本版本机推理与 DSH 验收

- 通过插件同一 JobQueue/runner 在本机实际生成 7 张普通静物测试图：基础、合成零增量 LoRA、移除 LoRA、ControlNet、蒙版、控制强度 0，以及 LoRA+ControlNet+蒙版组合。
- 合成 LoRA 的 2/2 键匹配并实际应用；零增量结果与基础图一致，移除 LoRA 后结果也一致，验证队列切换没有残留。
- ControlNet 0 与 0.8 的同种子结果不同；普通与组合蒙版任务的黑色区域均与原图逐像素一致。这验证调用与数据流，不代表任意第三方 LoRA 的视觉质量。
- 在重启后的 DSH 新会话（DeepSeek-V41-Flash）只输入普通茶壶摄影要求，不指定工具名。事件记录确认按 `skill(qwen-image)` → `qwen_generate_image` 执行，没有调用 shell 或独立脚本。
- 原生会话观察到 2/40 步；切到创作页观察到同一任务 4/40；返回会话继续到 10/40、23/40。切页未中断任务。
- 完成后，进度节点隐藏，独立会话图片卡片与模型回复正常显示；创作页保留同一结果。隐私模式开启时会话图片仍可见。
- 自然语言要求“取回已有结果，不重新生成”时，模型调用 `qwen_image_status`；两次结果的任务 ID、附件标识完全一致，图库中仍只有一条对应作品。
- 要求“只写一句摄影提示词，不生成”时，只返回文字，没有调用生图工具或脚本。
- 原生图库默认选择收藏；新图未收藏，因此在隐私图库中可见、收藏图库中不出现。原有配置文件校验值未变。
- 以上验证的是当前 DSH/DeepSeek-V41-Flash 的实际行为；其他模型是否正确选技能仍受其工具能力、会话上下文与权限影响。下节保留 2.2.0 原生记录。

# 2.2.0 已完成的验证记录

## 自动检查

- TypeScript 类型检查、17 项 Vitest 测试、11 项 Python worker 测试。
- 从独立目录安装锁文件依赖并构建，开发与运行均不依赖旧 dsh-image-gen 包。
- 安装包内容检查：前后端、技能、说明与许可证齐全；不含模型、运行数据、个人绝对路径或凭证。

## DSH 桌面端实测（2026-10-16）

- 使用 qwen_generate_image 生成普通静物图：512 × 512 / 30 步，以及 1024 × 1024 / 40 步。
- 对话进度实际显示到 34/40，切到创作页显示 37/40，再回会话显示 40/40；任务持续执行。
- 生成完成后进度占位卡片隐藏，独立图片结果卡片及模型回复继续展示；重开创作页保留同一图片结果。
- 验收发现 DSH 不允许撤销已发布节点，已改为保留节点身份并设置 hidden visibility，并加入回归断言。这里仅涉及临时进度卡片的生命周期。
- 隐私图库开启时，未收藏的新图正常显示在会话中；隐私偏好只改变图库分类。
- 步数和种子浮层均在本机确认完整显示，Escape 可关闭。
- 清除预览后画布恢复空白，生成文件仍保留，草稿参数未被会话任务覆盖。

## 边界

远程接口通过模拟服务验证协议，未覆盖所有远程 GPU 部署。独立 CLI 的功能不等于插件已提供相同入口。CI 不下载模型、不运行真实 GPU 推理。隐私图库不是加密或访问控制。
