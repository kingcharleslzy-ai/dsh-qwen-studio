# 图库隐私与创作参数界面

## 行为

- 隐私图库默认开启。图库默认显示未归档、未删除的收藏作品。
- 右上角筛选中可进入隐私图库，查看未收藏作品；开启时没有「全部作品」。
- 收藏/取消收藏改变两个图库间的可见性，不移动图片文件。所有生成来源共用此规则。
- 归档和回收站保持原有独立筛选及恢复语义。
- 插件设置里的隐私开关立即生效；关闭后恢复原来的全部作品视图。
- 隐私模式是本机界面偏好，不是加密或访问控制；对话里的生成进度、新图片和历史图片始终正常显示。
- 设置保存在 DSH WebView 的 `qwen-studio-private-gallery-v1` localStorage 项，缺省为 true。不会改写模型、接口或后台任务配置。

## 创作

- 清除预览会清空当前选中结果、最近创作缩略图和参考图关联，保留描述、参数、图库原件和后台任务。
- 结果预览可直接收藏，主图库也支持批量收藏和取消收藏。
- 步数、种子旁的问号支持悬停与键盘聚焦查看说明。
- 高级生成设置集中提供当前接口已支持的尺寸、步数、种子、参考图变化幅度和恢复默认参数。
- 高级设置直接保存至现有草稿，不改写已提交任务。

## 开发阶段的本机安装记录

界面验收阶段仅替换 `dsh-qwen-studio/lib/client.js` 和对应 source map。公开版本已把通用宿主与 worker 改动回收到源码，发布包包含完整前后端。保留用户其他会话对宿主 `lib/index.js`、独立 Python 服务及模型配置所作的改动。

## 验证

- `npm test`：12 项通过，覆盖收藏/隐私分流、默认开启、开关恢复、搜索和归档/回收站隔离。
- 浏览器交互夹具：清除后重新加载不恢复预览；收藏后从隐私移入收藏；关闭开关恢复全部作品；高级参数保存同步回创作页；问号说明可聚焦显示。
- DSH 原生窗口已验收：清除预览并切换页面仍为空；收藏/取消收藏分流；关闭/开启隐私开关立即恢复对应视图；说明提示与高级参数同步通过。测试收藏状态已还原，隐私保持开启，步数恢复为 20。

## 创作布局修复

- 标题与图库/创作导航合并为一行，顶部仅保留最多 28px 的窗口预留区。
- 高级设置入口放在生成参数标题旁，避免落到表单末尾。
- 生成按钮独立于参数滚动区，不遮挡字段；窄窗口仍允许整体滚动。
- 在本机当前窗口实际点击高级设置并返回，截图确认全部基本参数与生成按钮可见。

- 说明提示使用 body portal 与视口边界定位，避免参数滚动容器裁切；支持聚焦、悬停与 Escape 关闭。
