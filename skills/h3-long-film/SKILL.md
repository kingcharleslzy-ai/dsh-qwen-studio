# 用 H3 和本机剪辑工作流制作长片

用户说「做一个 2 分钟的视频」或要求多镜头完整 MP4 时，优先使用 h3_film_create、h3_film_next 和 h3_film_review。单独一个镜头仍用 h3_generate_video。按用户主题自行规划有开头、发展和结尾的分镜，以画面中的具体动作和声音承接前后；若未给题材，沿用当前对话的主题；空白对话中自行选一个适合该时长的题材，交付时说明选择。把「2 分钟」换算成 120 秒，所有镜头的剪辑秒数相加必须正好等于目标，每镜 1–15 整秒。选择最难的一镜作为 representative（从 1 开始计数）。在 prompt 写清主体、动作、机位、起止状态，保持人物造型及场景一致。纯文字默认走 480p Turbo，带参考图默认走 480p 质量档，用户说 768p 质量档时按原意选 quality768。需要解说时给每镜编写能在该镜内讲完的中文旁白；留白镜头可省略，明确要求无声则全片省略。原始模型音轨遵照本机剪辑设置剥离。

创建后保留项目 id，持续调用 h3_film_next。running 表示同一镜头在队列中；按同一项目 id 查询，不另建项目。review_shot 时检查返回的真实分镜样张及视频路径，按动作、连贯性、伪影和可用性给出具体结论。必要时播放未剪原片和裁齐的片段。用 h3_film_review 提交同一 review_token 的结论。需要重做时选 reject 并给出改进的 replacement_prompt。切勿凭任务成功自动批准。一次只审一个镜头，代表镜通过后自动进入余下镜头。不要要求用户逐镜操作。

一直跟进到 master_ready，返回可播放的完整 MP4、本机路径和实际时长。技术错误或中断按 id 恢复。完整视听播放后，可用 h3_film_finish_review 按母版 SHA-256 登记真实审片意见。未看完不得声称已通过创意终审。不要对外上传、分享或发布成片。

人物长片先用 h3_character_save 把用户提供的 1–5 张 DSH 图片附件保存成命名角色，再用 h3_character_list 取角色 ID。全片 character_ids 为默认阵容，有不同出场人物的镜头在 shots[].character_ids 覆盖，空镜传 []。按角色、图片的顺序在提示中绑定 <Picture 1> 等。带角色选 quality480 或 quality768；每镜最多九图。工程锁定建项时的参考图。先审最难的侧脸或换场镜头，与原图核对，通过后继续逐镜生成。

母版回执含 playback_markdown 时，把整行 Markdown 原样贴入最终回复，让用户直接在 DSH 对话内播放。
