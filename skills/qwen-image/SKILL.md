# 图像创作与迭代

## 何时使用

用户有生成意图时直接用 `qwen_generate_image`，例如“画一张窗边的蓝色陶瓷杯”“给文章做个封面”“沿用刚才那张的构图，再做一版水彩风格”。仅询问原理、讨论方案或搜索已有照片时，不自动生成。已有足够画面信息就执行；只有缺少不可推断的关键信息时才追问。

## 一次创作

1. 识别输出目的和用户的明确约束。组成完整的目标画面描述：主体、环境、构图、风格、光线，以及需要逐字保留的文字。中文提示词可直接使用，不要自动增加与请求无关的主体或风格。
2. 调用 `qwen_generate_image`。默认1024×1024、40步；横图1344×768、竖图768×1344。用户明确要求测试或草图时可用512×512及较低步数。不要自行把正式创作降到测试质量。
3. 工具会自动启动服务、排队、保存并返回图片附件；不要调用终端、安装软件、搜索本地文件或让用户手动启动服务。
4. 直接呈现图片结果，简短说明，不输出附件JSON或伪造图片URL。保留工具返回的完整任务ID供后续迭代；图像同时位于左侧「图像」图库。

## 继续调整

先区分两种需求，不能将“改提示词重画”冒充图生图：

- **重新构图/仅复用描述**：修改完整prompt，不传source_image_id。需要可重复比较时保持seed、尺寸、步数。
- **基于刚才的图片生成变体**：传之前工具返回的完整ID作为 `source_image_id`，并传 `change_strength`。默认0.45；轻微风格/光线变化可从0.2–0.35开始，较大重绘可用0.6–0.8。低值更接近原图，高值改变更多。prompt描述完整目标画面，并保留用户要求不变的主体、构图等。此参数是图生图变化幅度，不是提示词权重。

多轮“继续改这张”默认使用最近一张符合用户指代的结果；明确指定早期版本则使用该版本ID。存在多个同等可能的指代才询问。不要编造ID，不要把文件路径、附件哈希当成图片ID。

例如用户先要求“画一张窗边蓝色陶瓷杯”，成功返回ID后又说“保留构图，做成柔和水彩”：第二次调用沿用尺寸、种子，传上次ID、change_strength=0.35，prompt描述同一杯子、窗边构图与柔和水彩风格。实际结果可能改变细节，不声称精确保留。

## 本地可选采样参数

- `negative_prompt` 描述不希望出现的视觉特征，如模糊、蜡像质感。最多 8000 字符。
- Qwen Image 2.1 的负向分支需要非空负向词且 `guidance > 1`；只给负向词时，worker 会把默认 guidance 自动提升到 2.5，并记录到任务。无负向词时 guidance 不作为质量旋钮。
- `scheduler` 默认 `linear`；仅在用户明确需要时使用已支持的 `flow_match_euler_discrete` 或 `seedvr2_euler`。
- 以上参数只支持本地工具调用，尚未放入创作页高级设置；远程模式会明确拒绝，避免静默忽略。

## 能力边界与失败处理

- 当前本地模型支持文生图和以已生成图片为起点的强度式图生图；不支持上传附件作为输入、多图融合、蒙版/局部修补、精准自然语言编辑或视频。不要把“只修改某个字/只换一个物体、其他像素不动”承诺为当前能力。说明边界后由用户决定是否接受整体变体。
- 当前远程适配器仅支持文生图。带参考图的远程请求会明确报错，不能悄悄忽略参考图。
- 提交成功后等待超时/取消等待，不代表生成已取消。保留错误里的任务ID，先在左侧「图像」核对，不盲目重复生成。
- 生成失败如实报告；不要声称看见了不存在的图片。任务完成后的视觉质量仍应结合实际结果判断。
- 工具和技能不改变DSH权限或调用模型的行为规则。不自动外传或公开生成内容。
