# 图像：生成与任务恢复

## 执行路由

用户要出图时，使用已注册的 `qwen_generate_image`。它统一管理任务、按需启动、会话进度、图片附件与图库；提示词类技能负责画面描述，执行仍走此工具。若本技能正文已经完整注入，不重复加载。

- 常规生图、参考变体、负向提示词、CFG 与支持的调度器，优先用工具当前公布的参数。
- 不用终端、Python/MFLUX CLI、旧生图工具、直接 HTTP 请求或手写图库文件代替插件；不用安装软件、修改插件、运行补丁或手动启动服务。
- 工具缺失、参数未支持或失败时，如实说明具体情况，保留任务 ID。不要静默改跑脚本或切到其他服务。只有用户明确要求使用独立 CLI/其他产品时才采用其指定路线，并说明它不具备本插件完整的会话进度同步。
- 以当前工具 schema 为准。MFLUX 库、独立脚本或其他技能里写过的能力，不代表当前插件已接入。会话外部附件导入和精准指令编辑尚未接入；需要这些能力时先说明边界，等待用户选择，不偷偷改成普通重画。LoRA、图库控制图与蒙版按下节的限制使用。
- 仅要求提示词、解释原理、讨论画面或找已有图片时，不提交生图任务。

## 一次创作

1. 根据用户约束组成完整目标描述：主体、环境、构图、风格、光线及需逐字呈现的文字。中文可直接用，不添加无关主体或风格；关键缺失信息无法合理推断时再追问。
2. 调用 `qwen_generate_image`。默认 1024×1024、40 步；横图 1344×768、竖图 768×1344。只有用户明确要试稿/测试时使用 512×512 或低步数。
3. 工具执行期间，对话和左侧「图像」显示任务状态；本地提供真实采样步数，远程仅显示处理状态。不要编造百分比、耗时或实时半成品图片。
4. 成功后直接呈现工具图片附件，保留完整任务 ID 供后续迭代。无需再查找、复制、导入图片或把附件 JSON/文件路径当成图片展示。图库开启隐私模式时，未收藏结果进入隐私图库；对话中的图片与进度照常显示。

## 继续调整

- 重新构图或按新描述重画：使用完整 prompt，不传 `source_image_id`。
- 沿用上张图生成变体：传工具返回的 32 位任务 ID 为 `source_image_id`，配合 `change_strength`。默认 0.45；较低值更接近原图，较高值变化更大。描述完整目标，保留用户要求不变的主体和构图。
- 这是强度式图生图，不保证精准保留某个局部或仅修改指定像素。不要把“改提示词重画”说成参考编辑，也不编造任务 ID，不传文件路径或附件哈希充当 ID。
- 多轮“继续改这张”使用指代对应的结果；多个同等可能的版本才追问。固定尺寸、种子等参数有助于比较，但不保证不同运行环境逐像素一致。

## 查询与取回：qwen_image_status

收到提交回执或错误里的任务 ID 后，需要查进度、恢复结果或用户问“画好了吗/图在哪”时，调用 `qwen_image_status(id)`。它只读取任务；完成时直接返回同一张图的附件，不启动模型、不重新生成、不搜索文件。

- 任务仍在排队/加载/生成/保存：报告工具返回的状态，让现有进度卡片继续更新。不要紧密循环轮询，也不再提交同一请求。
- 任务已完成：直接展示返回图片；恢复结果不会创建第二张图库作品。
- 任务失败或已取消：说明具体错误；更正参数或明确重试前不自动再生一张。
- 任务不存在或已在回收站：说明状态，让用户在图库中核对；不要自行新建目录、改 job.json 或把独立脚本产物冒充原任务。
- 等待超时、网络中断或取消等待不等于取消后台生成。先查询已接受任务，避免重复开跑。

## 本地可选采样参数

- `negative_prompt`：不希望出现的视觉特征，最多 8000 字符。
- 只有非空负向词且 `guidance > 1` 时才计算负向分支；只给负向词时 worker 自动提升默认 guidance 至 2.5，并记录到任务。无负向词时 guidance 不作为质量旋钮。
- `scheduler` 默认 `linear`，仅在用户需要时选择已支持的 `flow_match_euler_discrete` 或 `seedvr2_euler`。
- 上述三项仅接入本地工具；远程明确报错，不会忽略参数继续生成。远程模式也不支持参考变体。

工具遵循 DSH 权限；不自动公开图片、切换服务或改变调用模型的行为规则。视觉质量依据实际返回结果判断，不声称看见尚未生成的图片。

## 本地高级工具参数

高级参数继续调用同一 `qwen_generate_image`，不改用独立脚本。先确认用户需要且已有对应资源，不自行下载权重或虚构路径/ID。

- `lora_paths` / `lora_scales`：1–8 个本机 `.safetensors`，文件须在插件设置的 LoRA 文件夹内，默认 `<图库目录>/loras`。权重数量需匹配，范围 0–2，缺省为 1。使用与 Qwen Image 2.1 匹配的 LoRA。切换组合或移除 LoRA 时后端重新加载模型，避免残留。
- `controlnet_image_id` / `controlnet_strength`：已有图库控制图的 32 位 ID，强度 0–1，默认 1。需本机完整的 Qwen Image 2.1 Union 控制权重。控制图限定结构，提示词定义内容；不可把普通重画声称为受控生成。
- `mask_image_id`：已有图库蒙版 ID，须同时提供 `source_image_id`；白色区域重绘，黑色区域从缩放到输出尺寸的原图复制。不传 `change_strength`。用户要求保留原像素时保持原尺寸。
- ControlNet/蒙版只支持默认 `linear`；蒙版可配控制图；只给控制图与源图而不提供蒙版会明确报错。用户可从「图像 → 创作 → 高级设置」选择本机控制图、原图和蒙版；会话工具仍只接收已存在的图片/资源 ID，不能把文件路径当 ID。
- 上述能力仅支持本地；缺权重、不兼容、ID 不存在等均报告实际错误，不自动换参数或脚本。创作面板高级设置也提供这组参数和本机文件选择；用户选择直接面板创作时无需通过文字模型。
